# 🌉 Drehbrücke

Ein endloses One-Tap-Handyspiel: Ein Balken dreht sich – tippe im richtigen Moment und bau deine Brücke Stück für Stück weiter. Je waagrechter, desto mehr Punkte.

**▶ Spielen:** https://nrplk.github.io/drehbruecke/

## Features
- Perfekt-Combos mit Buffs (ab x3 unverwundbar)
- Anker in Bodennähe als Sicherung
- Welten: Tag → Abend → Nacht → Winter
- Keine Höhengrenze: Stratosphäre → Weltall → fremde Galaxie
- Hindernisse: Bäume, Vögel, Ballons, Zeppeline, UFOs, Aliens, Asteroiden, Schwarze Löcher
- Power-ups: Schild, Magnet, Raketen-Schub
- Über 30 Skins mit Seltenheiten, Truhen ab 100 Punkten
- Level & XP, Erfolge, tägliche Aufgaben, Statistik, Bestenliste
